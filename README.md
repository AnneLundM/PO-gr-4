# Projektorganisering - Gruppe 4

Dette repository skal indholde jeres gruppearbejde i faget **Projektorganisering**. I skal arbejde efter Scrum-metoden på et udviklingsprojekt for **Gowala Farms** — en hjemmeside, der præsenterer gårdens produkter, værdier og historie.

## Om projektet

I skal udvikle en moderne og brugervenlig hjemmeside for Gowala Farms ud fra det udleverede Figma-design og data fra det tilhørende API. Da vi kun har få dage til opgaven, skal opgaverne prioriteres efter en MoSCoW-model (Must / Should / Could have).

Se det fulde produktmål og backlog i [ProductGoal+Backlog.md](ProductGoal+Backlog.md).
