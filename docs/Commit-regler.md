## Fælles regler for commit:

- Skriv commit-beskeder på engelsk, fordi det er almindelig praksis i kodeprojekter.
- Brug bydeform: “Add”, “Fix”, “Update”, “Remove”, “Refactor”.
- Lav ét commit pr. logisk ændring eller løst opgave.
- Undgå beskeder som “update”, “test”, “fix” og “rettelser”.
- Commit ikke node_modules, .env-filer, dist/build-mapper eller personlige filer.
- Henvis til GitHub Issues, når det giver mening: “closes #3”.
- Tjek altid git status og git diff før commit.
